# 机场服务商地图系统

一个基于中国省份地图的机场（VPN/代理服务）信息展示系统，可以按省份查看不同机场的节点分布和性能数据。

## 📁 项目结构

```
mapvpn/
├── data/
│   └── airports.json                # 机场数据文件
├── china-province-airports.html     # 主地图页面
├── airport-detail.html              # 机场详情页
├── airport-admin.html               # 数据管理后台
├── china-province-map.html          # 原始省份地图（参考）
├── vpn-speedtest-map.html          # 节点雷达（原有）
└── airport-speedtest-map.html      # 信号点位（原有）
```

## 🎯 功能特点

### 1. **地图可视化**
- 中国省份地图展示
- 有节点的省份高亮显示
- 点击省份查看该地区可用机场
- 响应式设计，支持深色模式

### 2. **机场信息展示**
- 机场基本信息（名称、档次、评分）
- 价格套餐（月付/季付/年付）
- 节点分布（按省份统计）
- 性能数据（速度、延迟、稳定性）
- 特性标签（流媒体解锁、游戏加速等）
- 支持协议展示

### 3. **数据管理**
- 可视化管理界面
- 添加/编辑/删除机场
- JSON 数据导入导出
- 表单验证

## 🚀 快速开始

### 方式一：直接打开文件

1. 用浏览器打开 `china-province-airports.html` 查看主地图
2. 点击省份查看该地区的机场列表
3. 点击机场卡片进入详情页

### 方式二：本地服务器（推荐）

```bash
# 进入项目目录
cd /Users/mac/mapvpn

# 启动本地服务器（Python）
python3 -m http.server 8080

# 或使用 Node.js
npx serve

# 访问 http://localhost:8080/china-province-airports.html
```

## 🔧 数据管理

### 使用管理后台

1. 打开 `airport-admin.html`
2. 点击"添加机场"按钮
3. 填写机场信息
4. 在"省份节点数据"中填写 JSON 格式的数据
5. 保存后可以下载更新的 JSON 文件
6. 将下载的 JSON 文件替换 `data/airports.json`

### 手动编辑 JSON

直接编辑 `data/airports.json` 文件，按照上述数据结构添加或修改机场信息。

## 🔒 注意事项

1. **数据安全**：敏感信息（如API密钥）不应存储在 JSON 文件中
2. **内容合规**：确保展示的机场信息符合当地法律法规
3. **数据准确性**：定期更新机场状态和价格信息
4. **用户隐私**：如果添加评论功能，注意保护用户隐私
5. **版权问题**：使用的 Logo 需获得授权
