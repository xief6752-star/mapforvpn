ClashX Pro 配置教程

适用于 macOS 10.15+ 系统 · 功能增强版

📥 下载 ClashX Pro

免费开源：ClashX Pro 是 ClashX 的增强版，支持更多协议。

下载渠道：从 GitHub 获取最新版本。

前往 GitHub 下载 →
1

下载并安装

从 GitHub 下载安装包：

  • 访问 GitHub Releases 页面
  • 选择最新版本（Latest）
  • 下载 ClashX.Pro.dmg 文件
  • 打开 DMG 文件，将 ClashX Pro 拖入"应用程序"文件夹
  • 首次运行需要在"系统偏好设置 → 安全性与隐私"中允许
💡 版本选择：ClashX Pro 相比标准版支持更多协议（如 TUN 模式），功能更强大。
2

获取订阅链接

从你的机场获取订阅链接：

  • 使用浏览器登录机场官网
  • 进入用户中心或仪表板
  • 找到"Clash 订阅"或"一键订阅"
  • 复制订阅链接
🔗 订阅格式：确保使用 Clash 格式的订阅链接，通常以 yaml 结尾或标注为 Clash 专用。
3

导入订阅配置

在 ClashX Pro 中添加订阅：

  • 点击菜单栏的 ClashX Pro 图标
  • 选择"配置 → 托管配置 → 管理"
  • 在弹出的窗口中点击"添加"
  • 在"Url"栏粘贴订阅链接
  • 在"Config Name"栏填写机场名称
  • 点击"确定"保存
4

更新并选择配置

更新订阅并激活配置：

  • 在托管配置管理窗口中，点击配置右侧的"更新"按钮
  • 等待更新完成（状态栏会显示进度）
  • 关闭管理窗口
  • 点击菜单栏图标，在"配置"菜单中选择刚添加的配置
🔄 自动更新：可以勾选配置的"自动更新"选项，ClashX Pro 会定期自动更新节点。
5

启用系统代理

开启 ClashX Pro 的系统代理：

  • 点击菜单栏的 ClashX Pro 图标
  • 选择"设置为系统代理"（勾选）
  • 首次使用会要求输入管理员密码授权
  • 菜单栏图标颜色变化表示代理已启用
🎯 出站模式：推荐使用"规则判断"模式，实现智能分流（自动判断国内外网站）。
6

选择代理节点

在策略组中选择节点：

  • 点击菜单栏的 ClashX Pro 图标
  • 找到"Proxy"或"节点选择"策略组
  • 选择一个具体节点，或选择"自动选择"
  • 可以点击"Proxy → 延迟测试"查看各节点延迟
⚡ 延迟测试：定期进行延迟测试可以帮助选择最快的节点，获得更好的使用体验。
7

验证连接

测试代理是否正常工作：

  • 打开浏览器访问 https://www.google.com
  • 如果能正常访问，说明配置成功
  • 可以在菜单中选择"控制台"查看实时连接日志
✅ 配置完成！ClashX Pro 支持开机自启、增强模式（TUN）等高级功能，可在设置中探索。
