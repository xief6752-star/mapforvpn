Quantumult X 配置教程

适用于 iOS 13+ 系统 · 功能强大的代理工具

📱 获取 Quantumult X

注意：Quantumult X 是付费应用，需要从 App Store 购买（美区 $7.99）。

购买方式：

  • 使用美区 Apple ID 登录 App Store
  • 搜索"Quantumult X"购买下载
  • 一次购买永久使用，支持多设备
1

下载并安装

从 App Store 下载 Quantumult X：

  • 切换到美区 Apple ID
  • 打开 App Store
  • 搜索"Quantumult X"（图标是蓝色 X）
  • 购买并下载（$7.99）
⚠️ 注意：Quantumult X（圈X）和旧版 Quantumult（圈）是两个不同的应用，请确认下载正确版本。
2

获取订阅链接

从你的机场获取订阅链接：

  • 使用 Safari 浏览器登录机场官网
  • 进入用户中心或仪表板
  • 找到"Quantumult X 订阅"或"一键订阅"
  • 复制订阅链接
💡 提示：部分机场提供一键导入功能，点击后自动跳转到 Quantumult X 并完成配置。
3

添加节点订阅

在 Quantumult X 中添加订阅：

  • 打开 Quantumult X
  • 点击右下角"三条横线"图标
  • 找到"节点"区域，点击右侧"添加"按钮
  • 在弹出的菜单中选择"添加订阅"
  • 粘贴订阅链接，可选填"标签"作为备注
  • 点击右上角"确定"
🔄 更新订阅：长按"节点"区域可以手动更新订阅，获取最新节点列表。
4

添加分流规则（推荐）

配置智能分流以实现国内直连、国外代理：

  • 点击右下角"三条横线"图标
  • 找到"分流"区域，点击右侧"添加"按钮
  • 选择"引用"添加规则订阅
  • 推荐使用机场提供的规则链接，或使用公共规则如：
  • https://raw.githubusercontent.com/DivineEngine/Profiles/master/Quantumult/Filter/China.list
📋 规则说明：分流规则决定哪些网站走代理、哪些直连。大多数机场会提供配套规则，优先使用机场提供的规则。
5

允许添加 VPN 配置

首次使用需要授权 VPN 权限：

  • 点击首页右上角的圆形开关
  • 系统会弹出"添加 VPN 配置"提示
  • 点击"允许"
  • 输入设备密码或使用 Touch ID / Face ID 验证
🔒 安全提示：这是 iOS 系统级权限，所有代理应用都需要此权限才能工作。
6

选择节点并启用

选择节点并启动代理：

  • 在首页点击"节点"图标（底部中间）
  • 在节点列表中选择一个节点（会显示蓝色勾选）
  • 返回首页，点击右上角的圆形开关启用
  • 开关变为彩色表示连接成功
⚡ 延迟测试：在节点列表页面右上角可以进行延迟测试，帮助选择最快的节点。
7

验证连接

测试代理是否正常工作：

  • 打开 Safari 访问 https://www.google.com
  • 如果能正常访问，说明配置成功
  • 顶部状态栏会显示"VPN"图标
  • 可在首页查看实时网速和流量统计
✅ 配置完成！Quantumult X 支持脚本和重写功能，可在设置中探索更多高级功能。
