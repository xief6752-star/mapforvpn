💬 常见问题

Q: Windows 平台选择哪个客户端最好？

推荐 Clash Verge Rev 或 Karing。Clash Verge Rev 功能全面、界面美观，适合新手；Karing 性能出色、自动优选节点。进阶用户可选 v2rayN。

Q: iOS 客户端都是付费的吗？

大部分优秀的 iOS 客户端是付费的（如 Shadowrocket $2.99），这是因为 App Store 的政策。也有免费选择如 Karing（通过 TestFlight 安装）。建议使用自己的美区账号购买正版，避免使用共享账号。

Q: 下载后如何使用？

下载并安装客户端后，需要从机场获取订阅链接，然后在客户端中导入订阅。具体步骤请查看使用教程页面。

Q: 官方下载和本站下载有什么区别？

官方下载指向 GitHub 或官网，保证是最新版本；本站下载是我们保存的备份版本，可能不是最新。建议优先使用官方下载，本站备份仅在官方无法访问时使用。

Q: Clash for Windows 还能用吗？

Clash for Windows 已于 2023 年停止更新，但现有版本仍可正常使用。推荐使用其继任者 Clash Verge Rev，功能更强大且持续维护。

Q: 如何选择适合游戏加速的客户端？

Windows 推荐使用 Netch，支持进程代理模式，可以只为游戏加速而不影响其他程序。也可以使用 Clash 的 TUN 模式实现全局代理。

Q: 客户端之间有什么区别？

主要区别在于：1）支持的协议类型（Clash 系列支持 Clash 配置，v2ray 系列支持更多协议）；2）界面设计和易用性；3）高级功能（规则定制、脚本支持等）。新手选择界面友好的即可，进阶用户可根据需求选择。

Q: 一个订阅可以在多个客户端使用吗？

可以。订阅链接可以在多个设备和客户端上使用，但要注意机场的设备数量限制。大多数机场允许 2-5 台设备同时在线。

Q: 杀毒软件报毒怎么办？

代理软件因其网络特性，可能被部分杀毒软件误报。从官方渠道下载的客户端是安全的，可以添加到杀毒软件的白名单中。

Q: 没有找到适合我的客户端？

页面列出的是主流和推荐的客户端。如果有特殊需求，可以访问客户端的 GitHub 页面查看更多选项，或查看机场的推荐。
