v2rayN 配置教程

适用于 Windows 7/10/11 系统 · 功能全面

📥 下载 v2rayN

下载最新版本的 v2rayN（包含 v2ray-core）

GitHub 官方下载 查看更多下载源
1

下载并解压

前往 GitHub 下载页面，下载最新版本：

  • 下载 v2rayN-With-Core.zip（带内核版本，推荐新手）
  • 解压到任意文件夹（建议放在 C:\Program Files\v2rayN）
  • 双击运行 v2rayN.exe
⚠️ 注意：v2rayN 是绿色软件，解压即用，不要删除解压文件夹中的任何文件。
2

获取订阅链接

从你的机场服务商获取订阅链接：

  • 登录机场官网，进入用户中心
  • 找到"订阅地址"或"通用订阅"
  • 复制订阅链接
💡 提示：v2rayN 支持多种订阅格式，包括 VMess、VLESS、Trojan、Shadowsocks 等。
3

添加订阅

在 v2rayN 中添加订阅：

  • 运行 v2rayN 后，图标会出现在系统托盘（右下角）
  • 右键点击托盘图标，选择"订阅分组" → "订阅分组设置"
  • 点击"添加"按钮
  • 在"地址(url)"框中粘贴订阅链接
  • 点击"确定"保存
4

更新订阅

更新订阅获取节点列表：

  • 右键托盘图标，选择"订阅分组" → "更新全部订阅（不通过代理）"
  • 等待更新完成，节点会显示在主窗口列表中
🔄 自动更新：可以在"设置" → "v2rayN设置" → "订阅"中设置自动更新间隔。
5

选择节点并启用

选择节点并启用系统代理：

  • 在主窗口节点列表中双击一个节点（节点会变为红色）
  • 右键托盘图标，选择"系统代理" → "自动配置系统代理"
  • 路由模式选择"绕过大陆"（国内直连，国外代理）
⚡ 测速技巧：可以选中多个节点，右键选择"测试服务器真连接延迟"，找出最快的节点。
6

验证连接

测试代理是否正常工作：

  • 打开浏览器访问 https://www.google.com
  • 如果能正常访问，说明配置成功
  • 托盘图标显示绿色表示连接正常，红色表示连接失败
✅ 配置完成！v2rayN 会在后台运行，可以设置开机自启，方便日常使用。
